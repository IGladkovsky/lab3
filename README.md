# Лабораторная работа №3

Разработанный внутренний сервис техподдержки HelpDesk Lite.
Сотрудник компании создаёт тикет с описанием проблемы,
а команда поддержки назначает исполнителя, меняет 
приоритет и переводит тикет по этапам обработки.

# Установка зависимостей

`pip install -r requirements.txt`

# Запуск

`fastapi dev starter.py`
